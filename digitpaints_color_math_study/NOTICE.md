# Provenance / Usage Note

This study was produced from:

1. code supplied by the user in the conversation,
2. publicly observable behavior and explanatory text on the live DigitPaints Color Mixer,
3. general mathematical interpretation of the resulting algorithm.

The implementation in `src/color-math.js` is rewritten with descriptive names, comments, validation, documentation, and a clean public API rather than copying the production bundle verbatim.

DigitPaints' published Terms and Conditions state that its service content/source code is protected and include restrictions on copying/adapting/reverse engineering. If you intend to redistribute a derivative of their software or use it commercially, review those terms and obtain permission where needed.

Relevant public pages checked during preparation:

- https://www.digitpaints.com/en/blog/how-to-mix-paints
